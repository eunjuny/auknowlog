# Git Fundamentals Quiz
총 5문항 · 정답 5 · 오답 0

## Q1. What is Git?
- A. A programming language for version control
- B. A distributed version control system
- C. An online code editor
- D. A cloud storage service for documents
✅ 내 답: A distributed version control system
설명: Git is a free and open-source distributed version control system designed to handle everything from small to very large projects with speed and efficiency.

## Q2. Which command is used to initialize a new Git repository in the current directory?
- A. git start
- B. git init
- C. git new
- D. git create
✅ 내 답: git init
설명: The `git init` command creates a new, empty Git repository or reinitializes an existing one. It creates the .git directory with all necessary repository files.

## Q3. What does the command `git add .` typically do?
- A. Commits all changes to the local repository
- B. Stages all modified and new files in the current directory for the next commit
- C. Deletes all untracked files from the working directory
- D. Clones a remote repository into the current directory
✅ 내 답: Stages all modified and new files in the current directory for the next commit
설명: The `git add .` command adds all changes (new, modified, and deleted files) in the current directory and its subdirectories to the staging area, preparing them for the next commit.

## Q4. In Git, what does a 'commit' represent?
- A. A new branch in the repository
- B. A saved snapshot of your project at a specific point in time
- C. A remote repository hosted on a server
- D. A merge conflict that needs to be resolved
✅ 내 답: A saved snapshot of your project at a specific point in time
설명: A commit is a fundamental concept in Git. It's a snapshot of your repository's state at a particular moment, including a unique identifier, a message, and pointers to the previous commit(s).

## Q5. Which command is used to download or clone a repository from a remote source (e.g., GitHub) to your local machine?
- A. git push
- B. git merge
- C. git clone
- D. git fetch
✅ 내 답: git clone
설명: The `git clone` command is used to create a copy of an existing Git repository from a specified URL. It downloads all repository data and sets up the remote tracking branches.
