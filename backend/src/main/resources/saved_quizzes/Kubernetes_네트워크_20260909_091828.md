# Kubernetes 네트워크
총 5문항 · 정답 5 · 오답 0

## Q1. Kubernetes에서 개별 컨테이너들이 같은 네트워크 공간을 공유하는 기본 배포 단위는 무엇인가요?
- A. 서비스(Service)
- B. 파드(Pod)
- C. 네임스페이스(Namespace)
- D. 컨트롤러(Controller)
✅ 내 답: 파드(Pod)
설명: Pod는 기본 네트워크 단위이며, 보통 하나의 애플리케이션 인스턴스를 담습니다.

## Q2. 클러스터 내부에서만 접근 가능한 기본 Kubernetes Service 타입은 무엇인가요?
- A. NodePort
- B. LoadBalancer
- C. ClusterIP
- D. ExternalName
✅ 내 답: ClusterIP
설명: ClusterIP는 클러스터 내부에서만 접근 가능한 기본 서비스 타입입니다.

## Q3. Kubernetes Service의 주된 역할은 무엇인가요?
- A. Pod 자체의 디스크를 관리한다
- B. Pod 앞단에서 안정적인 접근 지점을 제공한다
- C. 노드 간 스토리지를 복제한다
- D. 컨테이너 이미지를 배포한다
✅ 내 답: Pod 앞단에서 안정적인 접근 지점을 제공한다
설명: Service는 안정적인 단일 접점을 제공하고, 뒤의 Pod들로 트래픽을 분산합니다.

## Q4. Ingress의 일반적인 역할은 무엇인가요?
- A. 노드의 CPU를 스케줄링한다
- B. 외부 HTTP/HTTPS 트래픽을 라우팅한다
- C. 컨테이너 로그를 저장한다
- D. 파드 이미지를 빌드한다
✅ 내 답: 외부 HTTP/HTTPS 트래픽을 라우팅한다
설명: Ingress는 주로 HTTP/HTTPS 트래픽을 외부에서 클러스터 내부 서비스로 라우팅합니다.

## Q5. Kubernetes에서 CNI(Container Network Interface)는 무엇을 의미하나요?
- A. 컨테이너 빌드 도구
- B. Pod 네트워크를 구현하는 플러그인 표준
- C. 스토리지 암호화 방식
- D. 배포 전략
✅ 내 답: Pod 네트워크를 구현하는 플러그인 표준
설명: CNI는 Pod 네트워크와 IP 할당 등 클러스터 네트워킹을 구현하는 플러그인 표준입니다.
