# Kubernetes 운영 퀴즈
총 5문항 · 정답 4 · 오답 1

## Q1. 쿠버네티스에서 애플리케이션의 원하는 상태를 유지하고 롤아웃/롤백을 관리하는 리소스는 무엇인가요?
- A. Deployment
- B. Service
- C. ConfigMap
- D. Ingress
✅ 내 답: Deployment
설명: Pod가 죽어도 원하는 개수만큼 다시 띄우는 역할을 합니다.

## Q2. Pod IP가 바뀌어도 고정된 접근 지점을 제공하는 오브젝트는 무엇인가요?
- A. Node
- B. Service
- C. Secret
- D. Namespace
✅ 내 답: Service
설명: Service는 Pod를 하나의 안정적인 엔드포인트로 묶어줍니다.

## Q3. 애플리케이션 설정값을 코드와 분리해서 저장할 때 주로 사용하는 오브젝트는 무엇인가요?
- A. ConfigMap
- B. PVC
- C. DaemonSet
- D. StatefulSet
✅ 내 답: ConfigMap
설명: ConfigMap은 설정값, Secret은 민감한 정보를 저장합니다.

## Q4. 특정 Pod의 상태, 이벤트, 상세 정보를 확인하는 데 가장 적절한 명령은 무엇인가요?
- A. kubectl get nodes
- B. kubectl apply -f
- C. kubectl describe pod
- D. kubectl logs -f
✅ 내 답: kubectl describe pod
설명: kubectl describe는 상태와 이벤트를 볼 때 유용합니다.

## Q5. Pod가 트래픽을 받을 준비가 되었는지 확인하는 프로브는 무엇인가요?
- A. startup probe
- B. liveness probe
- C. readiness probe
- D. resource limit
❌ 내 답: liveness probe  |  정답: readiness probe
설명: liveness는 죽은 컨테이너를 재시작하고, readiness는 트래픽 받을 준비가 되었는지 확인합니다.
