# Kubernetes 핵심 개념
총 5문항 · 정답 5 · 오답 0

## Q1. 쿠버네티스에서 컨테이너를 배포하는 가장 작은 기본 단위는 무엇인가요?
- A. Node
- B. Pod
- C. Service
- D. Namespace
✅ 내 답: Pod
설명: Pod는 쿠버네티스에서 컨테이너를 배포하는 가장 작은 기본 단위입니다.

## Q2. 애플리케이션의 배포와 롤링 업데이트를 주로 관리하는 리소스는 무엇인가요?
- A. ConfigMap
- B. Deployment
- C. Ingress
- D. Secret
✅ 내 답: Deployment
설명: Deployment는 애플리케이션의 배포, 업데이트, 롤백을 관리하는 리소스입니다.

## Q3. Pod들에 대한 안정적인 네트워크 접근 지점을 제공하는 리소스는 무엇인가요?
- A. Service
- B. Job
- C. PersistentVolume
- D. ReplicaSet
✅ 내 답: Service
설명: Service는 Pod의 IP가 바뀌어도 안정적인 접근 경로를 제공합니다.

## Q4. 클러스터 내 리소스를 논리적으로 분리하는 데 사용하는 개념은 무엇인가요?
- A. Namespace
- B. DaemonSet
- C. Ingress
- D. Endpoint
✅ 내 답: Namespace
설명: Namespace는 클러스터 안에서 리소스를 논리적으로 분리하는 데 사용됩니다.

## Q5. Pod가 실제로 실행되는 워커 머신을 무엇이라고 하나요?
- A. Node
- B. Control Plane
- C. ConfigMap
- D. StatefulSet
✅ 내 답: Node
설명: Node는 Pod가 실제로 실행되는 워커 머신입니다.
