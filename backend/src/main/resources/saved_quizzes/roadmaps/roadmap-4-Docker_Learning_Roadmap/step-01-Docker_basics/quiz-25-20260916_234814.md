# Docker Overview
총 5문항 · 정답 4 · 오답 1

## Q1. Why do people use Docker instead of installing software directly on a host?
- A. It packages an application and its dependencies so it runs consistently across environments.
- B. It replaces the host operating system with a new one.
- C. It automatically makes every application run faster.
- D. It removes the need for any configuration files.
❌ 내 답: It replaces the host operating system with a new one.  |  정답: It packages an application and its dependencies so it runs consistently across environments.
설명: Docker helps avoid environment differences by packaging the app and its dependencies together.

## Q2. Which problem does Docker primarily help solve?
- A. To isolate apps and simplify deployment across machines with different setups.
- B. To eliminate the need for source code control.
- C. To store only database backups.
- D. To make programs run without any operating system.
✅ 내 답: To isolate apps and simplify deployment across machines with different setups.
설명: Docker reduces “works on my machine” problems by making deployments portable and consistent.

## Q3. What is the correct relationship between a Docker image and a container?
- A. An image is a running instance of software; a container is the template used to start it.
- B. An image is the template for starting a container; a container is a running instance of that image.
- C. A registry runs containers on the host; Docker Engine stores images remotely.
- D. Docker Engine is the packaged application; a registry is the container runtime.
✅ 내 답: An image is the template for starting a container; a container is a running instance of that image.
설명: Images are the immutable templates, and containers are the running instances created from them.

## Q4. What is the role of Docker Engine in a Docker workflow?
- A. Docker Engine is the runtime that builds and runs containers on the host.
- B. Docker Engine is a remote cloud service that stores only source code.
- C. Docker Engine is the name for a container image format.
- D. Docker Engine is the command used only to push images to a registry.
✅ 내 답: Docker Engine is the runtime that builds and runs containers on the host.
설명: Docker Engine is the core runtime responsible for building and running containers.

## Q5. How do containers remain isolated while running on the same host?
- A. Containers share the host kernel but are isolated using namespaces and cgroups.
- B. Each container runs its own separate full kernel.
- C. Containers can access every process and file on the host by default.
- D. Containers must always be inside a virtual machine to be isolated.
✅ 내 답: Containers share the host kernel but are isolated using namespaces and cgroups.
설명: At a high level, containers reuse the host kernel while OS features like namespaces and cgroups provide isolation and resource control.
