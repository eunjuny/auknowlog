# 네트워크 기본 상식 퀴즈
총 10문항 · 정답 10 · 오답 0

## Q1. 네트워크 장비 중 라우터(Router)의 주된 기능은 무엇인가요?
- A. 네트워크 내의 모든 장치에 신호를 증폭하여 재전송
- B. 다른 네트워크 간에 데이터를 전송하고 최적의 경로를 선택
- C. 물리적인 케이블 연결을 제공하여 데이터를 전송
- D. 네트워크 트래픽을 감시하고 침입을 방지
✅ 내 답: 다른 네트워크 간에 데이터를 전송하고 최적의 경로를 선택
설명: 라우터는 서로 다른 네트워크(예: LAN과 WAN) 간에 데이터를 전송하며, IP 주소를 기반으로 목적지까지의 최적 경로를 결정하여 패킷을 전달합니다.

## Q2. 허브(Hub)와 스위치(Switch)의 차이점에 대한 설명으로 올바른 것은?
- A. 허브는 데이터 충돌이 없고 스위치는 데이터 충돌이 많다.
- B. 스위치는 특정 포트로만 데이터를 전송하지만, 허브는 모든 포트로 데이터를 브로드캐스트한다.
- C. 허브는 MAC 주소를 학습하고, 스위치는 그렇지 않다.
- D. 스위치는 1계층 장비이고 허브는 2계층 장비이다.
✅ 내 답: 스위치는 특정 포트로만 데이터를 전송하지만, 허브는 모든 포트로 데이터를 브로드캐스트한다.
설명: 허브는 수신한 데이터를 연결된 모든 포트로 단순히 복사하여 전송(브로드캐스트)하므로 충돌이 발생하기 쉽습니다. 반면 스위치는 MAC 주소를 학습하여 목적지 MAC 주소를 가진 장치가 연결된 특정 포트로만 데이터를 전송합니다.

## Q3. 서브넷 마스크(Subnet Mask)의 역할은 무엇인가요?
- A. 네트워크에서 사용 가능한 IP 주소의 총 개수를 결정한다.
- B. IP 주소 내에서 네트워크 주소 부분과 호스트 주소 부분을 구분한다.
- C. 네트워크 트래픽을 암호화하여 보안을 강화한다.
- D. 라우터의 성능을 측정하는 데 사용된다.
✅ 내 답: IP 주소 내에서 네트워크 주소 부분과 호스트 주소 부분을 구분한다.
설명: 서브넷 마스크는 IP 주소가 어떤 네트워크에 속하는지를 결정하고, IP 주소의 어느 부분이 네트워크를 식별하고 어느 부분이 해당 네트워크 내의 특정 호스트를 식별하는지를 구분하는 데 사용됩니다.

## Q4. 네트워크의 가장 기본적인 정의는 무엇인가요?
- A. 데이터를 저장하는 단일 컴퓨터 시스템
- B. 서로 연결되어 정보를 교환할 수 있는 컴퓨터 및 장치들의 집합
- C. 인터넷에 접속할 수 없는 고립된 시스템
- D. 소프트웨어 개발을 위한 도구 모음
✅ 내 답: 서로 연결되어 정보를 교환할 수 있는 컴퓨터 및 장치들의 집합
설명: 네트워크는 둘 이상의 컴퓨터 또는 장치가 서로 연결되어 데이터를 공유하고 통신할 수 있도록 하는 시스템을 의미합니다.

## Q5. 네트워크에서 서로 다른 네트워크 간의 데이터 패킷을 전달하고 경로를 결정하는 장치는 무엇인가요?
- A. 허브 (Hub)
- B. 스위치 (Switch)
- C. 라우터 (Router)
- D. 리피터 (Repeater)
✅ 내 답: 라우터 (Router)
설명: 라우터는 서로 다른 네트워크 간의 데이터 패킷을 전달하며, 최적의 경로를 찾아 데이터를 전송하는 중요한 네트워크 장비입니다.

## Q6. 인터넷의 핵심 프로토콜 스위트이자 네트워크 통신에서 가장 널리 사용되는 프로토콜 집합은 무엇인가요?
- A. FTP
- B. HTTP
- C. TCP/IP
- D. SMTP
✅ 내 답: TCP/IP
설명: TCP/IP(Transmission Control Protocol/Internet Protocol)는 인터넷의 기반이 되는 프로토콜 스위트로, 데이터 전송과 네트워크 주소 지정 등 인터넷 통신의 핵심 기능을 담당합니다.

## Q7. OSI 7계층 모델에서 데이터 링크 계층(2계층)의 주요 기능은 무엇인가요?
- A. 물리적 연결 설정 및 유지
- B. 논리적 주소 지정 및 경로 설정
- C. 프레임 생성 및 오류 제어
- D. 애플리케이션 간의 데이터 통신
✅ 내 답: 프레임 생성 및 오류 제어
설명: 데이터 링크 계층은 물리 계층으로부터 받은 데이터를 프레임으로 구성하고, 물리적 주소(MAC 주소)를 통해 노드 간의 데이터 전송 및 오류 제어를 담당합니다.

## Q8. 별 모양으로 중앙 허브나 스위치를 중심으로 각 장치가 직접 연결되는 네트워크 토폴로지는 무엇인가요?
- A. 버스 토폴로지
- B. 링 토폴로지
- C. 스타 토폴로지
- D. 메시 토폴로지
✅ 내 답: 스타 토폴로지
설명: 스타 토폴로지는 중앙 장치(허브, 스위치)에 모든 장치가 점대점 방식으로 연결되는 형태를 말합니다. 중앙 장치에 문제가 생기면 전체 네트워크가 마비될 수 있지만, 한 장치의 고장이 전체 네트워크에 영향을 주지 않는다는 장점이 있습니다.

## Q9. 네트워크 보안을 위해 외부 네트워크로부터 내부 네트워크를 보호하고, 비인가 접근을 차단하는 시스템은 무엇인가요?
- A. VPN (Virtual Private Network)
- B. IDS (Intrusion Detection System)
- C. 방화벽 (Firewall)
- D. IPS (Intrusion Prevention System)
✅ 내 답: 방화벽 (Firewall)
설명: 방화벽은 미리 정의된 보안 규칙에 따라 네트워크 트래픽을 모니터링하고 제어하여, 잠재적으로 악성 트래픽으로부터 내부 네트워크를 보호하는 시스템입니다.

## Q10. 하나의 서버가 여러 클라이언트에게 서비스를 제공하는 네트워크 모델은 무엇인가요?
- A. P2P (Peer-to-Peer) 모델
- B. 클라이언트-서버 모델
- C. 분산 처리 모델
- D. 그리드 컴퓨팅 모델
✅ 내 답: 클라이언트-서버 모델
설명: 클라이언트-서버 모델은 서버가 자원과 서비스를 제공하고, 클라이언트가 이를 요청하여 사용하는 네트워크 구조입니다.
