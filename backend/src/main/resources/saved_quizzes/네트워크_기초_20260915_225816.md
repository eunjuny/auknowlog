# 네트워크 기초
총 4문항 · 정답 4 · 오답 0

## Q1. 네트워크의 기본 목적은 무엇인가요?
- A. 장치들 간에 데이터를 주고받기 위해서
- B. 컴퓨터의 전원을 공급하기 위해서
- C. 프로그램을 자동으로 설치하기 위해서
- D. 인터넷 속도를 항상 100배로 높이기 위해서
✅ 내 답: 장치들 간에 데이터를 주고받기 위해서
설명: 네트워크는 여러 장치가 서로 연결되어 정보를 교환할 수 있게 합니다.

## Q2. 다음 중 LAN에 대한 설명으로 가장 적절한 것은 무엇인가요?
- A. 가까운 범위의 작은 네트워크
- B. 전 세계를 연결하는 네트워크
- C. 위성만 사용하는 네트워크
- D. 전화선만으로 구성된 네트워크
✅ 내 답: 가까운 범위의 작은 네트워크
설명: LAN(Local Area Network)은 집, 학교, 사무실처럼 비교적 좁은 범위에서 사용하는 네트워크입니다.

## Q3. IP 주소의 역할은 무엇인가요?
- A. 네트워크에서 장치를 식별하는 주소
- B. 웹사이트의 색상을 정하는 값
- C. 파일의 크기를 줄이는 기능
- D. 컴퓨터의 배터리 상태를 나타내는 값
✅ 내 답: 네트워크에서 장치를 식별하는 주소
설명: IP 주소는 네트워크 안에서 각 장치를 구분하고 데이터를 올바른 곳으로 보내는 데 사용됩니다.

## Q4. 다음 중 라우터의 역할로 가장 적절한 것은 무엇인가요?
- A. 서로 다른 네트워크 사이의 데이터를 전달하는 것
- B. 화면 밝기를 조절하는 것
- C. 컴퓨터 내부 메모리를 늘리는 것
- D. 문서를 인쇄하는 것
✅ 내 답: 서로 다른 네트워크 사이의 데이터를 전달하는 것
설명: 라우터는 네트워크 간 경로를 정해 데이터를 전달하는 장비입니다.
