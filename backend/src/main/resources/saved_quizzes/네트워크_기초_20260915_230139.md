# 네트워크 기초
총 4문항 · 정답 3 · 오답 1

## Q1. 다음 중 스위치(Switch)의 역할로 가장 적절한 것은 무엇인가요?
- A. 같은 네트워크 내에서 목적지 장치로 데이터를 전달한다.
- B. 서로 다른 네트워크를 연결해 경로를 선택한다.
- C. 웹 사이트의 도메인 이름을 IP 주소로 변환한다.
- D. 공인 IP 주소를 사설 IP 주소로 바꾼다.
❌ 내 답: 서로 다른 네트워크를 연결해 경로를 선택한다.  |  정답: 같은 네트워크 내에서 목적지 장치로 데이터를 전달한다.
설명: 스위치는 MAC 주소를 바탕으로 같은 LAN 안에서 데이터를 전달합니다.

## Q2. DNS의 주요 기능은 무엇인가요?
- A. 도메인 이름을 IP 주소로 변환한다.
- B. 데이터를 암호화해 전송한다.
- C. 네트워크 충돌을 자동으로 방지한다.
- D. 패킷의 전송 속도를 높인다.
✅ 내 답: 도메인 이름을 IP 주소로 변환한다.
설명: DNS는 사람이 읽기 쉬운 도메인 이름을 네트워크에서 사용하는 IP 주소로 바꿉니다.

## Q3. 서브넷 마스크의 역할로 가장 적절한 것은 무엇인가요?
- A. IP 주소에서 네트워크 부분과 호스트 부분을 구분한다.
- B. 도메인 이름을 숫자 주소로 바꾼다.
- C. 데이터 전송 경로를 자동으로 선택한다.
- D. 무선 신호의 세기를 측정한다.
✅ 내 답: IP 주소에서 네트워크 부분과 호스트 부분을 구분한다.
설명: 서브넷 마스크는 한 IP 주소에서 네트워크 주소와 호스트 주소의 범위를 나누는 데 사용됩니다.

## Q4. TCP와 UDP에 대한 설명으로 가장 적절한 것은 무엇인가요?
- A. TCP는 신뢰성 있는 전송을 제공하고, UDP는 빠르지만 확인 절차가 단순하다.
- B. TCP는 데이터 압축을 담당하고, UDP는 암호화를 담당한다.
- C. TCP는 로컬 네트워크에서만 사용되고, UDP는 인터넷에서만 사용된다.
- D. TCP와 UDP는 모두 IP 주소를 부여하는 프로토콜이다.
✅ 내 답: TCP는 신뢰성 있는 전송을 제공하고, UDP는 빠르지만 확인 절차가 단순하다.
설명: TCP는 연결 지향적이며 오류 제어를 수행하고, UDP는 오버헤드가 적어 빠른 전송에 적합합니다.
