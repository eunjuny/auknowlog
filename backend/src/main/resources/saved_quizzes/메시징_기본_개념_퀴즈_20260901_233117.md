# 메시징 기본 개념 퀴즈
총 5문항 · 정답 4 · 오답 1

## Q1. 메시지 큐의 주요 목적은 무엇인가요?
- A. 생산자와 소비자를 느슨하게 결합하는 것
- B. 메시지를 항상 즉시 동기 처리하는 것
- C. 데이터를 암호화해 저장하는 것
- D. 네트워크 속도를 직접 높이는 것
✅ 내 답: 생산자와 소비자를 느슨하게 결합하는 것
설명: 메시지 큐는 생산자와 소비자를 분리해 비동기적으로 메시지를 주고받게 합니다.

## Q2. 발행된 메시지를 관심 있는 여러 구독자에게 전달하는 모델은 무엇인가요?
- A. 발행/구독 모델
- B. 요청/응답 모델
- C. 배치 처리 모델
- D. 단일 연결 모델
✅ 내 답: 발행/구독 모델
설명: Pub/Sub에서는 발행된 메시지를 관심 있는 여러 구독자가 각각 받을 수 있습니다.

## Q3. 메시지를 네트워크로 보내기 전에 전송 가능한 형식으로 바꾸는 과정은 무엇인가요?
- A. 직렬화
- B. 복제
- C. 인덱싱
- D. 압축
❌ 내 답: 인덱싱  |  정답: 직렬화
설명: 직렬화는 객체나 데이터를 전송 가능한 형식으로 바꾸는 과정입니다.

## Q4. 중복 메시지가 들어와도 결과가 동일하게 유지되도록 처리하는 성질은 무엇인가요?
- A. 멱등성
- B. 가시성
- C. 확장성
- D. 일관성
✅ 내 답: 멱등성
설명: Idempotent 처리는 같은 메시지가 여러 번 와도 결과가 같게 만드는 데 중요합니다.

## Q5. 메시지 브로커가 주로 수행하는 역할은 무엇인가요?
- A. 메시지를 중계하고 전달하는 역할
- B. 메시지를 직접 계산하는 역할
- C. 사용자 인증만 담당하는 역할
- D. 데이터베이스 스키마를 설계하는 역할
✅ 내 답: 메시지를 중계하고 전달하는 역할
설명: 메시지 브로커는 송신자와 수신자 사이에서 메시지를 받아 저장하고 전달합니다.
