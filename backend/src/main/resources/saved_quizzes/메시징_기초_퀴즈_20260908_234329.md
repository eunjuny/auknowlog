# 메시징 기초 퀴즈
총 5문항 · 정답 5 · 오답 0

## Q1. 메시징에서 소비자가 어디까지 읽었는지 나타내는 위치 정보는 무엇인가요?
- A. 오프셋
- B. 파티션
- C. 헤더
- D. 직렬화
✅ 내 답: 오프셋
설명: 큐에서 아직 처리하지 않은 위치를 나타내는 값입니다.

## Q2. 메시지를 전송하기 좋은 형태로 변환하는 과정을 무엇이라고 하나요?
- A. 직렬화
- B. 복제
- C. 압축
- D. 복호화
✅ 내 답: 직렬화
설명: 메시지를 미리 정해진 규칙에 따라 바이트 형태로 바꾸는 과정입니다.

## Q3. 한 시스템이 메시지를 보내고 그에 대한 답을 다시 받는 통신 방식은 무엇인가요?
- A. 요청-응답
- B. 발행-구독
- C. 브로드캐스트
- D. 폴링
✅ 내 답: 요청-응답
설명: 메시지를 먼저 받고, 나중에 응답을 돌려주는 방식입니다.

## Q4. 메시지 스트림을 나누어 병렬 처리하기 위해 사용하는 분할 단위는 무엇인가요?
- A. 파티션
- B. 라우터
- C. 세션
- D. 트랜잭션
✅ 내 답: 파티션
설명: 여러 소비자에게 작업을 나눠 처리하게 할 때 사용되는 기준입니다.

## Q5. 같은 메시지를 여러 번 처리해도 결과가 같게 유지되는 성질은 무엇인가요?
- A. 멱등성
- B. 일관성
- C. 내구성
- D. 가용성
✅ 내 답: 멱등성
설명: 한 번 처리한 메시지를 다시 받아도 같은 결과를 내도록 만드는 성질입니다.
