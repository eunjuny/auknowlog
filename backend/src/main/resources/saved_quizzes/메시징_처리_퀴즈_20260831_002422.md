# 메시징 처리 퀴즈
총 5문항 · 정답 5 · 오답 0

## Q1. 메시징 처리에서 메시지 큐의 주된 역할은 무엇인가?
- A. 생산자와 소비자를 분리해 비동기 전송을 돕는다
- B. 데이터베이스 정규화를 수행한다
- C. 화면 렌더링 속도를 높인다
- D. 네트워크 주소를 자동으로 할당한다
✅ 내 답: 생산자와 소비자를 분리해 비동기 전송을 돕는다
설명: 메시지 큐는 생산자와 소비자를 분리해 비동기 처리를 가능하게 한다.

## Q2. 메시지 처리에서 ACK의 의미로 가장 적절한 것은 무엇인가?
- A. 메시지 수신 확인 응답
- B. 암호화 키 교환
- C. 오류 로그 저장
- D. 중복 메시지 생성
✅ 내 답: 메시지 수신 확인 응답
설명: ACK는 메시지를 정상적으로 받았음을 알리는 확인 응답이다.

## Q3. 메시지 전송 실패 시 일반적으로 사용하는 복구 방식은 무엇인가?
- A. 재시도
- B. 압축 해제
- C. 캐시 삭제
- D. 화면 새로고침
✅ 내 답: 재시도
설명: 재시도는 일시적 장애로 실패한 전송을 다시 시도해 전달 성공률을 높인다.

## Q4. 메시지 순서를 보장할 때 가장 흔히 사용하는 개념은 무엇인가?
- A. FIFO
- B. 랜덤 우선순위
- C. 병렬 스왑
- D. 라운드 로빈
✅ 내 답: FIFO
설명: FIFO는 먼저 들어온 메시지를 먼저 처리하는 방식이다.

## Q5. 메시지 생산 속도가 소비자 처리 속도보다 훨씬 빠를 때 필요한 제어 개념은 무엇인가?
- A. 백프레셔
- B. 캐시 히트
- C. 로드 밸런싱
- D. 인덱싱
✅ 내 답: 백프레셔
설명: 큐 적재량이 많아지면 소비자 처리 속도를 조절하거나 확장하는 등의 백프레셔가 필요할 수 있다.
