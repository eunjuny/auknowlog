# 메시징 퀴즈
총 5문항 · 정답 5 · 오답 0

## Q1. 메시징의 가장 기본적인 개념으로 가장 적절한 것은 무엇인가요?
- A. 데이터를 직접 공유하는 방식
- B. 메시지를 주고받는 통신 방식
- C. 파일을 압축하는 방식
- D. 화면을 출력하는 방식
✅ 내 답: 메시지를 주고받는 통신 방식
설명: 메시징은 보통 한 구성 요소가 다른 구성 요소로 메시지를 보내고 받는 방식의 통신을 뜻합니다.

## Q2. 비동기 메시징의 특징으로 가장 적절한 것은 무엇인가요?
- A. 송신자와 수신자가 반드시 동시에 실행된다
- B. 메시지를 보낸 뒤 즉시 응답을 기다리지 않아도 된다
- C. 오직 한 번만 전송할 수 있다
- D. 네트워크를 사용하지 않는다
✅ 내 답: 메시지를 보낸 뒤 즉시 응답을 기다리지 않아도 된다
설명: 비동기 메시징은 보낸 쪽과 받은 쪽이 동시에 동작하지 않아도 됩니다.

## Q3. 메시징에서 메시지를 순서대로 임시 저장하는 데 자주 쓰이는 구조는 무엇인가요?
- A. 스택
- B. 큐
- C. 트리
- D. 배열
✅ 내 답: 큐
설명: 큐는 메시지를 순서대로 저장했다가 소비자가 가져가는 데 자주 사용됩니다.

## Q4. 여러 수신자가 같은 주제의 메시지를 받아볼 수 있는 방식은 무엇인가요?
- A. 발행/구독
- B. 단일 실행
- C. 직렬화
- D. 캐싱
✅ 내 답: 발행/구독
설명: 발행/구독 모델에서는 발행자가 주제를 발행하고 여러 구독자가 이를 받을 수 있습니다.

## Q5. 메시지 브로커의 역할로 가장 적절한 것은 무엇인가요?
- A. 메시지를 저장, 라우팅, 전달한다
- B. 화면을 렌더링한다
- C. 코드를 컴파일한다
- D. 사용자 비밀번호를 생성한다
✅ 내 답: 메시지를 저장, 라우팅, 전달한다
설명: 메시지 브로커는 송신자와 수신자 사이에서 메시지를 전달하고 관리합니다.
