# 메시징 퀴즈
총 5문항 · 정답 5 · 오답 0

## Q1. 메시징에서 비동기 처리를 가능하게 하는 가장 큰 장점은 무엇인가요?
- A. 발신자와 수신자의 결합도를 낮춘다
- B. 모든 메시지를 즉시 삭제한다
- C. 수신자가 반드시 같은 시간에 응답한다
- D. 메시지를 반드시 한 번만 전송한다
✅ 내 답: 발신자와 수신자의 결합도를 낮춘다
설명: 발신자가 수신자의 처리 완료를 기다리지 않고 다음 작업을 계속할 수 있게 해줍니다.

## Q2. 메시지 소비 후 처리 성공을 송신 측에 알리는 신호는 무엇인가요?
- A. Acknowledgement(ACK)
- B. Heartbeat
- C. Rollback
- D. Broadcast
✅ 내 답: Acknowledgement(ACK)
설명: ACK는 수신 측이 메시지를 정상적으로 받았음을 알리는 응답입니다.

## Q3. 처리할 수 없는 메시지를 따로 모아 분석하거나 재처리하는 데 쓰는 큐는 무엇인가요?
- A. Dead-letter queue
- B. Priority queue
- C. Session queue
- D. Request queue
✅ 내 답: Dead-letter queue
설명: 처리 실패나 만료된 메시지를 별도로 모아두는 큐입니다.

## Q4. 메시징 시스템에서 메시지 순서를 보장하는 데 가장 직접적으로 관련된 요소는 무엇인가요?
- A. 동일 파티션으로의 라우팅
- B. 메시지 압축
- C. 발신자 IP 주소
- D. 암호화 키 길이
✅ 내 답: 동일 파티션으로의 라우팅
설명: 메시지 순서 보장은 보통 같은 파티션이나 동일 소비 흐름에서 이루어집니다.

## Q5. 하나의 발행자가 보낸 메시지를 여러 구독자가 각자 받는 모델은 무엇인가요?
- A. Publish/Subscribe
- B. Point-to-Point
- C. Load Balancing
- D. Polling
✅ 내 답: Publish/Subscribe
설명: 한 메시지가 여러 소비자에게 각각 전달되는 구조를 뜻합니다.
