# 메시징 퀴즈
총 5문항 · 정답 5 · 오답 0

## Q1. 메시징에서 특정 주제별로 메시지를 묶어 전달할 때 주로 사용하는 개념은 무엇인가요?
- A. 토픽(topic)
- B. 큐(queue)
- C. 배치(batch)
- D. 트랜잭션(transaction)
✅ 내 답: 토픽(topic)
설명: 토픽은 주제별로 메시지를 분류해 발행-구독 모델에서 사용됩니다.

## Q2. 메시지가 일정 시간 안에 처리되지 않으면 자동으로 만료되도록 하는 설정은 무엇인가요?
- A. TTL(Time To Live)
- B. ACK(acknowledgment)
- C. FIFO(First In First Out)
- D. RPC(Remote Procedure Call)
✅ 내 답: TTL(Time To Live)
설명: TTL은 일정 시간이 지나면 메시지를 폐기하도록 해 오래된 메시지를 제거합니다.

## Q3. 메시지를 바로 전달하지 않고 일정 시간이 지난 뒤에 소비할 수 있게 하는 큐는 무엇인가요?
- A. 지연 큐(delay queue)
- B. 우선순위 큐(priority queue)
- C. 브로드캐스트(broadcast)
- D. 세마포어(semaphore)
✅ 내 답: 지연 큐(delay queue)
설명: 지연 큐는 지정한 시간 이후에 메시지를 소비자에게 전달하도록 만듭니다.

## Q4. 브로커가 재시작되어도 메시지를 잃지 않도록 저장해 두는 성질은 무엇인가요?
- A. 메시지 영속성
- B. 메시지 압축
- C. 메시지 직렬화
- D. 메시지 암호화
✅ 내 답: 메시지 영속성
설명: 영속성은 브로커가 재시작되더라도 메시지를 디스크 등에 저장해 유지하는 성질입니다.

## Q5. 같은 메시지를 여러 번 전송해도 브로커에 중복 기록이 발생하지 않도록 돕는 생산자 기능은 무엇인가요?
- A. 멱등 생산자(idempotent producer)
- B. 독점 소비자(exclusive consumer)
- C. 팬아웃(fan-out)
- D. 폴링(polling)
✅ 내 답: 멱등 생산자(idempotent producer)
설명: idempotent producer는 동일한 요청이 중복 전송되어도 중복 기록을 줄여 안전하게 처리하도록 돕습니다.
