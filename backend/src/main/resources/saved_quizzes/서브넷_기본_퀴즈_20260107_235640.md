# 서브넷 기본 퀴즈
총 3문항 · 정답 3 · 오답 0

## Q1. 서브넷의 주요 목적은 무엇인가요?
- A. 브로드캐스트 도메인 확장
- B. 네트워크 트래픽 감소 및 효율성 증대
- C. 네트워크 보안 강화
- D. IP 주소 관리 복잡성 증가
✅ 내 답: 네트워크 트래픽 감소 및 효율성 증대
설명: 서브넷은 큰 네트워크를 작은 논리적인 네트워크로 분할하여 브로드캐스트 도메인을 줄이고, 불필요한 트래픽을 감소시켜 네트워크 효율성을 높입니다.

## Q2. 서브넷 마스크는 IP 주소의 어떤 부분을 구별하는 데 사용됩니까?
- A. 포트 번호
- B. 프로토콜 유형
- C. 네트워크 부분과 호스트 부분
- D. MAC 주소
✅ 내 답: 네트워크 부분과 호스트 부분
설명: 서브넷 마스크는 IP 주소에서 네트워크 부분을 식별하고, 나머지 부분을 호스트 부분으로 구분하는 데 사용됩니다.

## Q3. 서브넷 마스크가 255.255.255.0인 서브넷에서 사용 가능한 호스트 IP 주소의 최대 개수는 몇 개입니까?
- A. 256개
- B. 255개
- C. 254개
- D. 128개
✅ 내 답: 254개
설명: 255.255.255.0 서브넷 마스크는 마지막 옥텟(8비트)이 호스트 부분을 나타냅니다. 따라서 2^8 = 256개의 주소가 가능하지만, 네트워크 주소와 브로드캐스트 주소 2개를 제외하면 256 - 2 = 254개의 호스트 IP 주소를 사용할 수 있습니다.
