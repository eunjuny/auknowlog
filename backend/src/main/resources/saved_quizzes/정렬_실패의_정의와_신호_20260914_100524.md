# 정렬 실패의 정의와 신호
총 4문항 · 정답 4 · 오답 0

## Q1. 정렬 실패의 가장 알맞은 정의는 무엇인가요?
- A. 기대한 순서나 기준에 맞게 항목이 배열되지 않은 상태
- B. 항목이 무작위로 생성되는 과정
- C. 모든 항목이 같은 값으로 바뀌는 상태
- D. 항목 수가 자동으로 증가하는 현상
✅ 내 답: 기대한 순서나 기준에 맞게 항목이 배열되지 않은 상태
설명: 정렬 실패는 정해진 기준대로 순서가 맞지 않게 배열된 상태를 뜻합니다.

## Q2. 정렬 실패를 의심할 수 있는 신호로 가장 적절한 것은 무엇인가요?
- A. 순서가 뒤섞이거나 기준과 다르게 배치된 모습
- B. 처리 속도가 빨라진 모습
- C. 항목의 크기가 모두 같아진 모습
- D. 항목이 하나도 표시되지 않는 모습
✅ 내 답: 순서가 뒤섞이거나 기준과 다르게 배치된 모습
설명: 정렬이 실패하면 보통 순서가 어긋나거나 기준과 다른 배치가 나타납니다.

## Q3. 다음 중 정렬 실패의 예로 가장 적절한 것은 무엇인가요?
- A. 오름차순으로 정렬해야 하는데 중간 값이 앞에 오는 경우
- B. 모든 항목이 입력된 순서대로 유지되는 경우
- C. 항목이 색상별로 구분되어 표시되는 경우
- D. 같은 항목이 두 번 저장되는 경우
✅ 내 답: 오름차순으로 정렬해야 하는데 중간 값이 앞에 오는 경우
설명: 정렬 기준이 오름차순인데 값의 위치가 어긋나면 정렬 실패 신호로 볼 수 있습니다.

## Q4. 정렬 실패가 확인되었을 때 가장 먼저 할 일로 알맞은 것은 무엇인가요?
- A. 정렬 기준을 확인하고, 재정렬 또는 오류 원인을 점검한다
- B. 항목을 그대로 두고 결과만 무시한다
- C. 정렬 기준을 바꾸지 않고 무작정 반복한다
- D. 항목 수를 줄여서 문제를 없앤다
✅ 내 답: 정렬 기준을 확인하고, 재정렬 또는 오류 원인을 점검한다
설명: 정렬 실패가 보이면 먼저 기준을 확인하고 다시 정렬하거나 원인을 찾아야 합니다.
