- A. 클라이언트의 실제 IP를 숨기고 대신 요청을 전달하는 것

- C. 웹사이트의 화면을 자동으로 번역하는 것
- D. 암호를 저장해 두었다가 자동 입력하는 것
✅ 내 답: 클라이언트의 실제 IP를 숨기고 대신 요청을 전달하는 것
설명: 서버가 클라이언트의 실제 IP를 직접 보지 못하게 하려면 중간에 프록시가 필요합니다.

## Q3. 프록시의 캐싱 동작에 대한 설명으로 가장 적절한 것은 무엇인가요?
- A. 정적 이미지나 파일을 임시 저장해 반복 요청을 줄이는 것
- B. 인터넷 연결이 끊겨도 모든 사이트를 실시간으로 동기화하는 것

- D. 사용자 계정을 자동으로 생성하는 것

- B. 하나의 서버만 직접 호출하는 방식
- C. 같은 요청을 동시에 여러 서버에 중복 저장하는 방식
- D. 클라이언트 없이 서버끼리만 통신하는 방식
✅ 내 답: 여러 프록시를 순차적으로 거쳐 요청을 전달하는 방식
