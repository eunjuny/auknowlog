# Auknowlog 포트폴리오 리뉴얼 노트

## 한 문장 소개

AI가 만든 퀴즈를 단순 생성에 그치지 않고, 중복을 줄여 학습 이력으로 저장하는 개인화 학습 기록 서비스입니다.

## 이번 개선에서 보여줄 수 있는 역량

- **외부 AI 연동 고도화**: Gemini 전용 형식에서 OpenAI Responses API로 전환하고 JSON Schema 기반 Structured Outputs를 적용했습니다.
- **신뢰성**: 일시 장애만 제한 재시도하고, 모델 출력도 문항 수·보기 수·정답 일치까지 검증합니다.
- **입력 품질**: Bean Validation으로 빈 주제와 범위를 벗어난 문항 수를 API 경계에서 차단합니다.
- **학습 도메인**: 퀴즈 생성에서 끝나지 않고 풀이·오답 복습·학습 자료를 관계형 데이터로 관리합니다.
- **데이터 품질**: PostgreSQL 정확 해시와 pgvector 의미 유사도를 조합해 중복 문제를 낮춥니다.
- **테스트 가능성**: 외부 OpenAI 호출을 모킹하고, AI 응답 형식과 API 요청 검증을 자동화했습니다.
- **실제 인프라 검증**: Testcontainers로 PostgreSQL 16 + pgvector를 격리 실행해 Flyway V3, HNSW와 코사인 검색을 CI 경로에서 검증했습니다.

## 다음 스프린트 제안

1. **학습 대시보드**: 날짜·주제·난이도별 정답률, 오답 노트, 재학습 큐를 제공합니다.
2. **퀴즈 설정 확장**: 난이도, 문항 유형(개념/실무/디버깅), 언어, 세부 주제를 입력받습니다.
3. **운영 품질**: 추가된 Testcontainers·GitHub Actions를 기반으로 헬스체크와 구조화 로그를 배포 환경에 연결합니다.
4. **AI 품질 평가**: 대표 주제별 고정 평가셋으로 형식 준수율, 중복률, 사용자 정답률, 생성 지연시간·비용을 기록합니다.
5. **저장 경험 정리**: Git 커밋/푸시 전 사용자 확인, 저장 이력, Notion 링크를 UI에 명확히 표시합니다.

## 이력서·면접 서술 뼈대

"AI 퀴즈 생성 서비스를 구조화 출력 방식으로 재설계하고, 학습 자료·풀이·복습을 관계형 도메인으로 모델링했습니다. 모델 응답 검증과 제한 재시도, PostgreSQL 정확 해시와 pgvector 의미 중복 검사, 토큰·지연 원장을 적용해 AI 기능을 운영 가능한 학습 흐름으로 만들었습니다."
