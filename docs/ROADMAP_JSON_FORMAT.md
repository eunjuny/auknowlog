# `.roadmap.json` 학습 로드맵 형식

## 형식 선택

단계별 학습 계획의 원본 형식은 `*.roadmap.json`으로 정한다. Mermaid는 단계 관계를 보기 좋게 그리는 표현 형식이지만, 완료 기준과 진행 상태를 안정적으로 검증·저장하는 데이터 계약으로 쓰기에는 모호하다.

JSON을 사용하면 다음 이점이 있다.

- 필드 타입, 필수값, 최대 길이와 지원 버전을 서버에서 검증할 수 있다.
- Git diff에서 단계와 선행 조건의 변경을 확인할 수 있다.
- 백엔드, 프론트엔드, AI 생성 기능이 같은 계약을 공유한다.
- Mermaid, 트리, 타임라인 같은 화면은 저장된 JSON을 기준으로 안전하게 파생할 수 있다.

## 파일 계약 v1.0

파일명은 반드시 `*.roadmap.json`이어야 하고 최대 크기는 128KB다. 현재 지원하는 `version`은 `1.0`이다.

| 필드 | 역할 | 제한 |
| --- | --- | --- |
| `version` | 파일 계약 버전 | `1.0` |
| `title` | 로드맵 이름 | 필수, 최대 120자 |
| `topic` | 전체 학습 주제 | 필수, 최대 120자 |
| `description` | 전체 목표 설명 | 선택, 최대 2,000자 |
| `durationWeeks` | 예상 학습 기간 | 1~52주 |
| `steps` | 순서가 있는 단계 목록 | 1~20개 |
| `steps[].key` | 다른 단계가 참조하는 안정적인 식별자 | 영문·숫자·`-`·`_`, 최대 64자 |
| `steps[].topic` | 이 단계에서 생성할 문제의 주제 | 선택, 비우면 전체 주제 |
| `steps[].questionTarget` | 단계를 완료하는 데 필요한 풀이 문항 수 | 1~20문제 |
| `steps[].dependsOn` | 먼저 완료해야 할 단계의 `key` 목록 | 없는 단계·자기 참조·순환 참조 금지 |

예제는 [Kubernetes 로드맵](examples/kubernetes.roadmap.json)에 있다.

## 실행 흐름

1. 사용자가 화면에서 단계를 직접 작성하거나 `*.roadmap.json`을 선택한다.
2. 서버가 확장자, 크기, JSON 구조, 지원 버전과 단계 의존성을 검증한다.
3. 원본 JSON은 재현용으로 보관하고, 단계와 선행 관계는 PostgreSQL 테이블에 정규화해 저장한다.
4. 선행 단계가 완료되지 않은 단계는 `LOCKED`가 된다.
5. 사용자가 시작 가능한 단계에서 퀴즈를 생성하면 `learning_quiz.roadmap_step_id`로 연결된다.
6. 답안을 제출해 자동 저장된 풀이 문항 수가 목표에 도달하면 그 단계는 `COMPLETED`가 되고 다음 단계가 자동으로 열린다.

파일 가져오기와 직접 작성은 OpenAI API를 호출하지 않는다. AI 로드맵 생성도 같은 JSON 계약을 반환하고 서버 검증을 거치며, 사용자가 `AI로 로드맵 생성` 버튼을 누른 시점에만 모델 토큰을 사용한다.
