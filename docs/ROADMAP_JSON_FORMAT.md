# `.roadmap.json` 학습 로드맵 형식

## 형식 선택

단계별 학습 계획의 원본 형식은 `*.roadmap.json`으로 정한다. Mermaid는 단계 관계를 보기 좋게 그리는 표현 형식이지만, 완료 기준과 진행 상태를 안정적으로 검증·저장하는 데이터 계약으로 쓰기에는 모호하다.

JSON을 사용하면 다음 이점이 있다.

- 필드 타입, 필수값, 최대 길이와 지원 버전을 서버에서 검증할 수 있다.
- Git diff에서 단계와 선행 조건의 변경을 확인할 수 있다.
- 백엔드, 프론트엔드, AI 생성 기능이 같은 계약을 공유한다.
- Mermaid, 트리, 타임라인 같은 화면은 저장된 JSON을 기준으로 안전하게 파생할 수 있다.

## 파일 계약 v1.1

파일명은 반드시 `*.roadmap.json`이어야 하고 최대 크기는 128KB다. 현재 `1.0`과 `1.1`을 읽을 수 있으며, 대주제·소주제 계층을 표현하는 신규 파일과 AI 생성 결과는 `1.1`을 사용한다.

| 필드 | 역할 | 제한 |
| --- | --- | --- |
| `version` | 파일 계약 버전 | 신규 파일은 `1.1` |
| `title` | 로드맵 이름 | 필수, 최대 120자 |
| `topic` | 전체 학습 주제 | 필수, 최대 120자 |
| `description` | 전체 목표 설명 | 선택, 최대 2,000자 |
| `durationWeeks` | 예상 학습 기간 | 1~52주 |
| `steps` | 순서가 있는 대주제 목록 | 실제 학습 범위에 맞게 구성, 절대 안전선 10개 |
| `steps[].key` | 다른 대주제가 참조하는 안정적인 식별자 | 영문·숫자·`-`·`_`, 최대 64자 |
| `steps[].topic` | 소주제가 없을 때 생성할 문제의 주제 | 선택, 비우면 전체 주제 |
| `steps[].questionTarget` | 소주제가 없으면 실제 목표, 소주제가 있으면 소주제 목표의 합 | 단독 학습 단위는 최대 20문제, 소주제 합계는 최대 200문제 |
| `steps[].dependsOn` | 먼저 완료해야 할 대주제의 `key` 목록 | 없는 대주제·자기 참조·순환 참조 금지 |
| `steps[].subtopics` | 대주제 아래에서 순서대로 진행할 소주제 | 선택, 실제 학습 범위에 맞게 구성, 대주제별 절대 안전선 10개 |
| `steps[].subtopics[].key` | 대주제 안에서 고유한 소주제 식별자 | 영문·숫자·`-`·`_`, 최대 48자 |
| `steps[].subtopics[].topic` | 해당 소주제 퀴즈를 생성할 구체적인 주제 | 선택, 비우면 대주제 주제와 소주제 이름을 조합 |
| `steps[].subtopics[].questionTarget` | 소주제를 완료하는 풀이 문항 수 | 1~20문제, 개념 범위·난이도에 맞게 구성 |

소주제가 없으면 대주제 하나가 그대로 학습 단계가 된다. 소주제가 하나 이상이면 대주제의 `questionTarget`은 각 소주제 목표의 합과 정확히 같아야 한다. 대주제와 대주제별 소주제는 각각 최대 10개이며, 펼친 전체 학습 단위는 최대 100개다. 각 학습 단위는 최대 20문제이므로 전체 로드맵의 이론적 절대 상한은 2,000문제다. 이 값은 채워야 할 할당량이 아니라 비정상 payload의 메모리·DB 자원 고갈을 막는 절대 안전선이다. AI는 최대치를 목표로 삼지 않고, 중복 없는 학습 목표를 충족하는 가장 작은 구성과 문제 수를 우선한다.

예제는 [Kubernetes 로드맵](examples/kubernetes.roadmap.json)에 있다.

## 실행 흐름

1. 사용자가 화면에서 대주제와 선택적 소주제를 작성하거나 `*.roadmap.json`을 선택한다. AI 생성은 먼저 저장되지 않은 편집용 미리보기로 반환한다.
2. 서버가 확장자, 크기, JSON 구조, 지원 버전과 대주제 의존성을 검증한다.
3. 소주제가 없는 대주제는 하나의 단계로, 소주제가 있는 대주제는 소주제별 단계로 펼친다.
4. 같은 대주제의 소주제는 입력 순서대로 선행 관계를 자동 연결하고, 다음 대주제는 앞 대주제의 마지막 학습 단위에 연결한다.
5. AI 미리보기에서는 대주제·소주제 이름, 설명, 순서와 목표 문제 수를 수정할 수 있다. 사용자가 최종 저장을 누른 경우에만 편집한 JSON을 다시 검증한다.
6. 확인된 원본 JSON은 재현용으로 보관하고 펼친 단계와 선행 관계는 PostgreSQL에 정규화해 저장한다.
7. 사용자가 시작 가능한 대주제 또는 소주제에서 퀴즈를 생성하면 `learning_quiz.roadmap_step_id`로 연결된다.
8. 답안을 제출해 목표 문항 수에 도달하면 다음 소주제 또는 다음 대주제가 자동으로 열린다.

파일 가져오기와 직접 작성은 OpenAI API를 호출하지 않는다. AI 로드맵 생성은 주제 범위·난이도·자료 분량·기간을 기준으로 필요한 대주제 수, 각 대주제의 소주제 수와 목표 문제 수를 스스로 정한다. 고정된 개수를 채우기 위한 주제 부풀리기나 생략을 금지하고, 생성 결과는 v1.1 편집 미리보기로 반환한다. `AI 미리보기 생성` 시점에만 모델 토큰을 사용하며, 편집 후 `최종 저장`은 OpenAI를 다시 호출하지 않는다. 저장 학습 자료를 선택한 경우에는 앞에서부터 최대 8개 청크를 근거 문맥으로 함께 보내고, 최종 저장된 로드맵은 `source_document_id`로 원문과 연결한다.

`questionTarget`은 한 번의 API 응답 수가 아니라 해당 학습 단위를 완료하기 위한 누적 목표이며 최대 20문제다. 실제 생성에서 중복 필터링 등으로 목표보다 적은 문제가 반환되면 여러 학습 세션의 풀이 수를 누적해 완료한다.
